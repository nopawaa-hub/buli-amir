📋 Panduan Guru & Arahan Menjalankan Fail

1. Cara Menyimpan & Menjalankan Fail (index.html)

  1. Simpan kod permainan ini sebagai satu fail bernama index.html di komputer riba anda.
  2. Pastikan komputer riba mempunyai sambungan internet supaya pustaka pengesanan tangan MediaPipe Hands dan fon dapat dimuatkan daripada CDN.
  3. Buka fail index.html menggunakan pelayar web moden seperti Google Chrome atau Microsoft Edge.
  4. Untuk kamera web berfungsi tanpa sekatan keselamatan pelayar, jalankan terus dari pratonton ini, melalui pelayan tempatan (contohnya VS Code Live Server / python3 -m http.server), atau buka terus di Chrome dan klik “Allow / Benarkan” apabila diminta akses kamera.

2. Cadangan Pelaksanaan Aktiviti Kelas (Projektor)

  • Bahagikan murid Tahun 5 kepada beberapa kumpulan (2 hingga 5 kumpulan).
  • Bagi setiap kes, beri masa kepada ahli kumpulan untuk berbincang sebelum seorang wakil tampil ke hadapan komputer riba guru.
  • Wakil kumpulan menggunakan gerakan tangan cubit udara (ibu jari + jari telunjuk) untuk mengambil kad jawapan dan melepaskannya di dalam Kotak Sasaran.
  • Jika pencahayaan bilik darjah terlalu gelap atau kamera tidak dapat digunakan, wakil murid boleh terus menyeret atau mengklik kad jawapan menggunakan tetikus (mouse).
